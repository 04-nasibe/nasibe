# Nasibe Kardaş'ın Portföy Sayfası

Bu proje, Nasibe Kardaş için bir kişisel portföy sayfası oluşturmak amacıyla geliştirilmiştir. Proje modern tasarım teknikleri, React.js ve CSS kullanılarak inşa edilmiştir.

## Özellikler

- **Kişisel Bilgiler:** Ad, e-posta ve adres bilgileri.
- **Eğitim Bilgileri:** Üniversite, bölüm ve mezuniyet yılı.
- **Yetenekler:** Yazılım dilleri ve diğer yetkinlikler.
- **Hobiler ve İlgi Alanları:** Bireysel ilgi alanlarının listesi.
- **Sertifikalar:** Sahip olunan önemli sertifikalar.
- **Sosyal Medya:** LinkedIn, Twitter ve Instagram profillerine bağlantılar.

## Proje Yapısı

### 1. Kaynak Dosyalar
- **index.html**: React uygulamasını çalıştırmak için kullanılan temel HTML dosyası.
- **main.jsx**: Uygulamayı başlatan ve DOM ile ilişkilendiren React dosyası.
- **App.jsx**: Ana uygulama bileşeni; tüm içerik burada tanımlanır.
- **App.css**: Sayfa stilini düzenleyen CSS dosyası.
- **index.css**: Temel temaları ve genel stilleri barındıran CSS dosyası.

### 2. Klasör Yapısı
```plaintext
├── src
│   ├── App.jsx
│   ├── App.css
│   ├── index.css
│   ├── main.jsx
├── public
│   ├── assets
│       ├── profile-picture.jpg
├── index.html
```

## Kullanılan Teknolojiler
- **React.js:** Kullanıcı arayüzü oluşturma.
- **CSS:** Modern ve duyarlı tasarım için.
- **Vite:** React uygulamasını hızlı bir şekilde çalıştırmak için kullanılan geliştirme sunucusu.
